Voice permission

Grant the microphone to Ag once. Browser voice then uses the extension origin instead of asking each website.

Experimental

Prototype voice transport, off by default. When on, browser voice tries a LiveKit room minted by the gateway; on any error it falls back to the standard WebSocket voice path.

Voice-first mark gestures, off by default. When on: click once to start or stop and send voice in the current thread; hold for push-to-talk and release to send; double-click to start or stop voice in a fresh thread; triple-click to open chat. When off, single click opens the text surface as before.

Background automation

Off by default. Turning this on lets the configured gateway poll for browser work, advertise browser tools, open background tabs, and run bounded actions through the extension's local allowlist. Turning it off stops new claims and heartbeats; already-claimed work may finish so it is not stranded.

User scripts

Off by default. These switches control Chrome's isolated user-script runtime. Installed tools can run only after you review their exact source, input schema, and URL scope; generated programs still require their own scoped authority.

Each changed source revision still requires an exact source, digest, scope, timing, and approval match. Scripts use the isolated USER_SCRIPT world only.
Separate opt-in for installed browser tools and confirmed Delegate programs. MAIN remains a separate visible grant. If Chrome reports “Allow User Scripts” is off, enable it on this extension's details page.

Installed browser tools

Review and save exact read tools that agents may call on matching pages. The extension validates arguments, runs the code in Chrome's USER_SCRIPT world, and records source and input digests. Page content cannot add tools. Turn on Background automation so the gateway can discover and invoke them.
