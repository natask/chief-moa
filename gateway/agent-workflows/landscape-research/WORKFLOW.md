# Landscape Research Workflow

Use this directory when the broker routes broad research, comparison, online
search, prior art, market, or optimal-path questions.

## Agent Contract

- Start from the broker event and any linked session/project context.
- Search current sources when facts, tools, APIs, pricing, competitors, or
  recommendations may have changed.
- Record search queries and sources in the research output.
- Return a recommendation with tradeoffs and implementation implications.
- Link durable conclusions back to OpenSpec, a tracked ticket, or a scratch
  research artifact.

## Verification

- Store research outputs under `reference/scratch/landscape-research` or an
  active OpenSpec change.
- Cite sources for web-backed claims.
