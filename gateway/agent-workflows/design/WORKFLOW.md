# Design Workflow

Use this directory when the broker routes frontend, visual design, interaction
model, layout, or UX QA work.

## Agent Contract

- Read the target surface and existing design conventions before editing.
- Build the actual usable surface, not a marketing placeholder.
- Verify text fit, hierarchy, responsiveness, and interaction behavior.
- Capture screenshots for browser/app surfaces when visual behavior changes.
- Keep visual changes tied to product behavior and the active OpenSpec/task.

## Verification

- Run the target surface verify command.
- Capture before/after screenshots when practical.
- For text-heavy UI, run viewport/text overflow checks.
