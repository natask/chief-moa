# Writing Workflow

Use this directory when the broker routes writing, editing, copy, docs, posts,
emails, or voice/style work.

## Agent Contract

- Preserve the user's intent and product language.
- Do not replace durable product decisions with chat-only prose.
- Store architecture, workflow, or product changes in the correct repo artifact.
- Do not hand-edit generated `CHANGELOG.md`.

## Verification

- Check edited docs for consistency with `README.md`, `ARCHITECTURE.md`, and
  `AGENT_WORKFLOW.md`.
- Verify any command snippets or file paths are accurate.
