Subscription Agent Control Plane Research

No single existing product covers the whole request. The practical path is a Chief Moa-owned control plane that joins OAuth grants, credentials, browser sessions, subscriptions, CH-backed history, and durable agent work.

Top Recommendation

Use CH/common-chat as the owned history substrate, add a CASS/AgentsView-style search index, add a Nango/Auth0/Arcade-style grant registry, broker raw credentials through 1Password/Infisical-style controls, and persist all work through Moa broker events, work nodes, artifacts, approvals, and receipts.

Best Fit By Layer

History CH + CASS/AgentsView patterns

CH is the local owned substrate. CASS and AgentsView show the stronger retrieval and dashboard shape.

Credentials Nango/Auth0 + 1Password/Infisical

Separate OAuth grants from raw secrets. Agents request capabilities, not plaintext credentials.

Provisioning SCIM + browser session vault

Provision only owned or authorized personas. Use leased browser profiles for user-supervised web sessions.

Orchestration DBOS/Temporal + LangGraph concepts

Durable queues and approvals underneath; agent threads, interrupts, and streaming above.
