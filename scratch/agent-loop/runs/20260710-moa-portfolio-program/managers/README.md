# Manager launch directory

Each `goal_*.md` is a launch shim. The complete hard contract, dependency DAG,
quality/resource gates, audit blockers and escalation rules are authoritative in
`../portfolio-managers.md`; the shim fixes identity, ownership and lane so a
session manager cannot silently reinterpret them. A launcher must attach both
files plus parent instructions, named OpenSpecs, research/auditor packets and
prior implementation notes.
