# Goal: M5 stable protocol and native surfaces

Compile and execute M5 from `../portfolio-managers.md`,
`../intent-execution-map.md`, `define-aggie-compatible-surface` and parent
instructions. Start with branch/worktree `agent/m5-surface-protocol` /
`chief-moa-worktrees/m5-surface-protocol`. Own the typed session/event/action/
receipt facade, echo adapter and N/N-1 compatibility fixtures. Do not redesign
gateway identity, provider routing or canonical product data.

Run read-only research in parallel for protocol topology, reconnect/replay and
offline failure, trust/permission boundaries, resource/accessibility gates, and
current official macOS/iOS/Windows signing/update APIs. Research the best
available protocol model and platform-specialist executors; record unavailable
model attempts and fallbacks. Vision is allowed only with actual render evidence.

The protocol contractor freezes exact messages, versions, bounds, backoff,
dedupe, stale-action policy and receipts before native implementation. It must
set no-UI-thread-blocking, battery/network budgets, complexity <=10/CRAP <=15,
and exact compatibility/security commands. Auditors cover correctness,
security/trust, performance/resource, quality/complexity/CRAP, anti-gaming and
protocol integration.

After protocol and MX prerequisites are green, create separate serial lanes:
`agent/m5-macos-surface`, then `agent/m5-ios-surface`, then
`agent/m5-windows-surface`, with matching worktrees. Each owns only native UI,
accessibility, permissions, secure token storage, local action validation,
receipts and signed update integration for its OS. The unresolved companion
versus seamless-assistant visual direction permits only small reversible UX
prototypes, not an invented permanent architecture.

Gates: strict Aggie spec, facade text/live/event and echo smokes, N/N-1 matrix,
then platform build/UI/accessibility/security, isolated signed update rollback
and real-device smoke. Block provider keys, proposal auto-execution, protocol
forks, screenshot-only proof or unsigned updates. Signing/device gaps are
explicit unknowns. Never infer one OS's measured evidence for another.
