# Self-Hosted Alpha

## ADDED Requirements

### Requirement: The alpha has a reproducible and honest self-host path

Before public release, the project SHALL provide licensing, security guidance,
a clean-machine gateway path, one packaged client path, known limitations, and
documented uninstall and rollback steps.

#### Scenario: a new builder follows the golden path

- GIVEN a clean supported machine and user-owned provider credentials
- WHEN the builder follows the alpha documentation
- THEN they can complete one deterministic or configured text turn
- AND can remove the installation without an undocumented active service.
