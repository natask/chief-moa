# Open Source Engineering Strategy

## ADDED Requirements

### Requirement: Contributors have one verifiable engineering entrypoint

The repository SHALL document owner surfaces, trust boundaries, OpenSpec usage,
verification commands, and the definition of done from its contributor-facing
entrypoints.

#### Scenario: a contributor prepares a surface change

- GIVEN a contributor starts from the repository README
- WHEN they follow the engineering guidance
- THEN they can identify the owning surface and required verification
- AND can find the repository trust-boundary and completion rules.
