2. Generate candidates without ranking them.
3. Give each candidate to a separate clean evaluator.
4. Use the same problem statement and rubric for every candidate.
5. Hide competing evaluations from each evaluator.
6. Run independent falsifiers only after the neutral evaluations.
7. Give retained evaluations and falsifier findings to a fresh adjudicator.
8. Preserve rejected terms and their elimination evidence.
9. Permit different winners for the user-facing and durable-object layers.
