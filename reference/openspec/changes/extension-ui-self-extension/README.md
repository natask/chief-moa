# extension-ui-self-extension

Stage 2 (deferred design): the extension's own UI can gain new elements/features; open question is custom-built vs agent-generated.

Captured 2026-06-25: the default browser behavior must stay one Aggie per top-level page after restart/reload/reinjection. A future playful mode can intentionally let Aggie duplicate itself, move around the page, morph, or change mascot/icon, but that should be an explicit opt-in behavior from the self-extension UI layer rather than accidental duplicate overlay roots.
